# Media placeholders

No image is included in this work package. Each row is a placeholder for an item that stage 8 may link to a person or place, with the provenance and licence check that must be done before any file is added ([dataset strategy, section 8](../../../authoring/dataset-strategy.md#8-evidence-sources-and-licensing), point 9). An item enters the dataset only when its licence is recorded as compatible.

**No photographs of living people.** None of the candidates shows a living person.

**What a media item needs in the app.** A title, the file, where it came from (repository and reference), the licence, and the person or event it is attached to. The manual shows this with M01 once its reproduction and terms are settled.
