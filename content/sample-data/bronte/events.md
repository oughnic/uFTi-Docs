# Events

Every event the dataset records, with its date and place **exactly as each source gives them**. Where two sources give different values, both are shown and the row points to the thread (T) or smaller discrepancy (D) in [research-threads.md](research-threads.md). "Not found" means we looked in the sources listed in the claim and did not find it; it does not mean the event did not happen. Claim ids (C) are rows in the [evidence register](evidence-register.md).

Stage 2 records births and deaths with the people. Stage 4 adds the rest. "Publication" is the custom event type the manual uses for a book. The census, probate and memorial rows are used by stage 8.
