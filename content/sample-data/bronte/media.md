# Media placeholders

No image file is in this repository. M01 to M04 are placeholders for stage 8. M05 to M08 are images on Wikimedia Commons, linked by their addresses (DEC-120): M05 to M07 are linked from the sourced sample files, and M08 is printed for Journey 7, which is in no sample file. Each item's provenance and licence check comes first ([dataset strategy, section 8](../../../authoring/dataset-strategy.md#8-evidence-sources-and-licensing), point 9). An item enters the dataset only when its licence is recorded as compatible.
