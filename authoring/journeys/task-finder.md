# Task finder: "I want to"

Part of [WP0](README.md). Status: draft for testing, 16 October 2026. The task finder is the second entry on every manual's home page, after the Quick Start ([content model, section 3](../content-model.md#3-the-quick-start)). About twenty links, each in the reader's words, each to one planned topic.

## Rules

- **The reader's words.** Each entry starts "I want to" and says what the reader wants, not what the feature is called. "Say where I found something", not "Add a citation".
- **One line, one topic.** An entry opens one topic. If two topics are needed, the first one links to the second.
- **About twenty on the home page.** More would be a contents list. The rest are reached by search and the navigation.
- **Ordered by how often the journeys need them.** The first entries serve the most journeys.
- **Keywords feed search.** The "words readers might search" column goes into each topic's keywords, so search finds the page from the reader's own words ([content model, section 9](../content-model.md#9-progressive-disclosure)).
- **Topic titles are provisional** until WP4's inventory fixes them. Chapters follow the order proposed in the [README](README.md#5-what-the-journeys-decide).

## Left off, and why

- "I want to add DNA results." One topic covers DNA, on its risks and issues (DEC-037). There is nothing to add.
- "I want to sync between my phone and my laptop." Not until a service ships (DEC-040). The export entry carries this need for now.
- "I want to merge my cousin's changes into my tree." The app has no way we can document ([Journey 6](journey-6-sharing-with-family.md), step 6).

## How it is tested

Part C of the [novice sessions](novice-session-plan.md) reads five "I want to" questions to each participant and asks which entry they would choose. Four of five must pick the right entry. Any entry nobody picks correctly is reworded.

## The top ten tasks

The journeys name these as the ten tasks to write first (DEC-044). Entries 1 to 12 in the list cover them, with two entries for families and dates kept apart because readers ask for them in different words.

6. Add an event
7. Add a source to a fact
8. Add a photo
9. Import a family tree file
10. Export a family tree file

Near misses, written straight after: Add a note, Enter a date you are not sure of, Add a research note, Share a copy of your tree.
