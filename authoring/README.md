# Authoring documents

Planning and standards for the uFTi user documentation. These files guide authors and maintainers. They are **not** DITA content and are not published to the website or the PDF.

| Document | What it answers |
|---|---|
| [authoring-plan.md](authoring-plan.md) | What are we building, for whom, in what order, and how will we know it is done? |
| [content-model.md](content-model.md) | How does the documentation serve people who never read manuals: tiers, the Quick Start, journeys, in-app help, learning modalities? |
| [platform-strategy.md](platform-strategy.md) | How do we document one app on several platforms without copying content? |
| [screenshot-strategy.md](screenshot-strategy.md) | How are screenshots chosen, captured, imported, reviewed and kept current? |
| [dataset-strategy.md](dataset-strategy.md) | What is the worked example, and how do we build and check it? |
| [good-practice-strategy.md](good-practice-strategy.md) | How do we teach family history research good practice to readers who are new to it? |
| [site-strategy.md](site-strategy.md) | What does ufti.com hold, where do the manuals sit, and what collateral is needed? |
| [authoring-standards.md](authoring-standards.md) | How is DITA written here: structure, naming, markup, metadata, accessibility, style? |
| [build-and-quality.md](build-and-quality.md) | Which tools build the outputs, and which checks must pass before anything is published? |
| [decision-log.md](decision-log.md) | What has been decided, what is proposed, and what still needs an answer? |
| [review-draft-0.3.md](review-draft-0.3.md) | What was wrong with Draft 0.3, and what changed because of it? |

**Status:** Draft 0.4, 16 October 2026. Nothing here is final until its entry in the decision log is marked *Accepted*.

## Reading order

1. The [authoring plan](authoring-plan.md), for the whole picture.
2. The [decision log](decision-log.md), for the questions that need an answer before work starts.
3. The other documents as you need them.

## Keeping these documents current

- When a decision is made or changed, update the decision log in the same change.
- Facts about tools (versions, parameters, known limits) were checked against the upstream projects on 15 October 2026. Check them again at the start of WP1.
- Section numbers are linked from elsewhere in the repository. If you renumber a section, search for links to it.
