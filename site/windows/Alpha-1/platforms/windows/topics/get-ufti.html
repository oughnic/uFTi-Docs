Get uFTi

Download uFTi, install it and open it for the first time.

About this task

A workspace is one family tree.

Procedure

  1. Download the installer from the Get uFTi page on the uFTi website.
  2. Run the installer.
  3. Open uFTi from the Start menu.

    The Workspaces screen opens.

Results

This is where your trees live. You may see some sample workspaces already. You do not need them.
