# uFTi brand artwork

**Artwork version 1.1.0**

The sampler mark (#1655) is a cross-stitch tree on linen. Victorian samplers were where families stitched their names. The colours are from the Oxford and slate theme: Oxford-blue thread on slate linen. The tree's fruit is stitched in the app's three evidence colours: sound (green), uncertain (amber) and unsourced (blue).

Every file here is generated by `tools/brand/Build-BrandArtwork.ps1` from one 16 × 16 stitch map. To change a stitch, a colour or a claim, edit the script and rerun it; never edit the files. The same run writes the app's icon layers and splash screen (`uFTi.app/Resources/AppIcon`, `uFTi.app/Resources/Splash`). `tools/brand/BrandExport.cs` (run by the script) turns text into outlines and draws the PNGs and the `.ico`.

## Files

**The mark**

| File | What it is |
|---|---|
| `ufti-sampler.svg` | The master: the mark on a light rounded tile with a running-stitch border |
| `ufti-mark.svg` | The mark alone, transparent background, for light backgrounds |
| `ufti-mark-on-dark.svg` | The mark alone in light thread, transparent background, for dark backgrounds |
| `ufti-sampler-16.svg`, `-32`, `-48` (`.svg` and `.png`) | Pixel versions: at 16 px one stitch is one pixel, and 32 and 48 are exact multiples. Use them at those sizes only. |
| `ufti.ico` | Favicon: the 16, 32 and 48 px pixel versions in one icon |
| `ufti-touch-icon.svg` | Opaque square with a margin, for icons a platform rounds itself |
| `ufti-icon-180.png` | Touch icon for web pages on iPhone and iPad (`apple-touch-icon`) |
| `ufti-icon-300.png`, `-512.png`, `-1024.png` | Store icons: Microsoft Store listing (300), Google Play (512), App Store (1024, opaque) |

**Artwork with text.** Each comes three ways: `.svg` with live text (it loads the app's fonts from `uFTi.app/Resources/Fonts`, so it works only inside this repository); `-outlined.svg` with the text as outlines (no fonts needed: use this one anywhere else, and for print); and `.png`.

| Name | Size | Use |
|---|---|---|
| `ufti-box-front` | 1200 × 1600 | Box front |
| `ufti-hero` | 1920 × 1080 | Store hero art, the docs site, slides |
| `ufti-play-feature` | 1024 × 500 | Google Play feature graphic |
| `ufti-share-card` | 1200 × 630 | Link previews (Open Graph, social sites, chat apps) |

Every SVG carries a `<title>` and a `<desc>`, and a comment naming the artwork version and these terms. In an outlined file, each line of text keeps its words in a `<title>` on its path.

The strapline is **Understanding family tree information**. The fonts are the app's: Source Serif 4 for the name, Atkinson Hyperlegible Next for the rest.

## The claims the artwork makes

The text artwork says: every device (Windows, Mac, iPhone, iPad and Android); GEDCOM 7, with GEDCOM 5.5.1 files kept safe; evidence first (every fact tied to its source); and three colour themes, light or dark. They live in one list, `$Claims` in the script.

Review them against every release:

- they must match what ships and what the documentation says;
- the platform list follows what ships;
- they never gain a price, an account, a sign-in or a storage claim.

Platforms appear as plain device outlines, never as the platforms' own logos.
