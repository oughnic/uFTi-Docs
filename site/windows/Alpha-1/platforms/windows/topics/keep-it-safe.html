Keep it safe

Save a copy of your tree as a file, and keep it somewhere else too.

Procedure

  1. Open Workspaces.
  2. On the card for your tree, choose Save as….

    A small sheet named Save workspace as opens.

  3. Choose how to save your tree.
    • GEDZIP archive (.gdz) — includes media saves everything in one file, with its pictures. Choose this one.
    • GEDCOM file (.ged) saves your tree as a family tree file, without pictures. Use it only for a program that cannot read GEDZIP.
  4. If you chose GEDCOM file (.ged), choose a version.

    The box named Which version of GEDCOM? offers GEDCOM 7 (recommended) and GEDCOM 5.5.1 (for older programs). Choose the first unless a program you use is old.

  5. When Windows asks where to put the file, choose a folder you will remember.

    Windows opens your Documents folder first. Choose the folder you want, then choose Save.

    A message names the file and its folder. It stays until you choose it.

Results

You now have a copy. Make a new one after you add a lot. Keep one on another drive too.

If you opened a file from another program, uFTi saves your changes to that file. To leave the original alone, open a copy.
